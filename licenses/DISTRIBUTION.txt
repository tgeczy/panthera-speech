Panthera's original source and normal Windows, Android and native i686 Linux
builds are distributed under the MIT license. No Apple engine, voice or
dictionary data is distributed. The user supplies that data separately.

Normal Android builds use Box86 on ARMv7, Box64 on ARM64, and the Glint AAC
decoder. These projects retain their MIT notices. Additional permissive
notices from Box components, the LLVM and Kotlin runtimes, the BSD-licensed emoji
translation, and Unicode data accompany the APK. Use Full licenses to read
the included terms. Third-party components retain their own licenses.

Windows prefers Media Foundation and carries Glint as a fallback when the
Windows AAC codec cannot initialize. Native i686 Linux uses Glint by default
and runs the guest instructions directly. 64-bit ARM Linux runs them through
Box64, as the Android phones do, with Glint; that build is MIT as well. The
command-line renderer, streaming pipe protocol and C library can be used by
independent clients.

Optional comparison builds using Unicorn or FAAD2 remain GPLv2 distributions.
They are explicitly selected, and are not the normal Android or native Linux
builds. Keep their GPL/FAAD2 notices and corresponding source archives with
those binaries. The experimental Linux x86_64 Unicorn build belongs to this
group even when its AAC decoder is Glint, as does an aarch64 build made with
PANTHERA_RUNTIME=unicorn instead of the normal Box64 one.

Runtime Library Exception 3.1. Its notice, license and exception accompany
those binaries. This is a compiler runtime exception, not a change to
Panthera or Glint source licensing.
